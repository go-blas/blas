# blas

Pure-Go BLAS with the Fortran reference signatures, column-major: real
(`float32`/`float64`) level 1, gemv and level 3 (gemm, trsm, trmm, syrk, syr2k,
symm), with a SIMD GEMM on six
architectures, error bounds stated per routine, and a netlib-exact option.
Complex (c/z) BLAS and LAPACK are next.

```go
import "github.com/go-blas/blas"

// C := alpha*op(A)*op(B) + beta*C, column-major, as DGEMM. a is m x k, b is
// k x n, c is m x n, with leading dimensions lda, ldb, ldc.
err := blas.Dgemm(blas.NoTrans, blas.NoTrans, m, n, k, 1, a, lda, b, ldb, 0, c, ldc)
```

## Status

First release line, real routines only:

| Level | Routines (`S` and `D`) |
|---|---|
| 3 | `Strsm`/`Dtrsm`, `Strmm`/`Dtrmm`, `Ssyrk`/`Dsyrk`, `Ssyr2k`/`Dsyr2k`, `Ssymm`/`Dsymm`, blocked on the packed GEMM (a residual bound for trsm, see [docs/design.md](docs/design.md) decision 9) |
| 3 | `Sgemm`, `Dgemm`; `SgemmStrided`, `DgemmStrided` (row and column stride per operand, as BLIS's `bli_?gemm`, no copy of a sliced or transposed view); `HasSgemmKernel` |
| 2 | `Sgemv`, `Dgemv` |
| 1 | `Sdot`/`Ddot`, `Saxpy`/`Daxpy`, `Sscal`/`Dscal`, `Snrm2`/`Dnrm2`, `Sasum`/`Dasum`, `Isamax`/`Idamax` |

The signatures are the reference's, parameter for parameter, so that a Fortran
ABI shim (julia's libblastrampoline, for one) can call them exactly:
column-major storage, leading dimensions, increments (negative ones included),
`beta = 0` never reads C, `alpha = 0` never reads A or B, the reference's quick
returns. `Idamax` and `Isamax` return the 1-based Fortran index.

## No routine panics

Each routine returns an `error`: nil, or a `*blas.ArgError{Routine, Param}`
carrying xerbla's parameter number (`Info()` is LAPACK's `-Param`). Beyond the
reference's own tests, every slice is checked against the length the call needs,
`lda*(cols-1)+rows` for a matrix and `1+(n-1)*|inc|` for a vector, with
overflow-safe arithmetic that also holds on 32-bit targets; a slice that is too
short is reported against its own parameter number.

## The contract is an error bound, not bit identity

Each routine states an elementwise error bound, asserted in the tests against a
`math/big` oracle of 256 bits (for `Dgemm`, with `u` the unit roundoff and
`gamma_k = ku/(1-ku)`:
`|C^ - C| <= gamma_{k+2} (|alpha||op(A)||op(B)| + |beta||C|)`; the others are in
the package comment). Inside the bound, FMA, packing, blocking and reordered
sums are all used. Bit identity with netlib is not promised.

`Dgemm` and `Sgemm` run on a packed, cache-blocked, multicore SIMD kernel
(AVX2/FMA on amd64, NEON on arm64, VSX on ppc64le, LASX on loong64, RVV on
riscv64, the vector facility on s390x), moved here from
[go-ndarray/ndarray](https://github.com/go-ndarray/ndarray). The column-major
product is the row-major product `C^T = op(B)^T op(A)^T`, so the one strided
kernel serves both layouts and no operand is copied beyond the kernel's own
packing.

## `netlib`, the exact option

`github.com/go-blas/blas/netlib` has the same routines as plain-Go ports of
reference BLAS 3.12 (`dgemm.f`, `sgemm.f`, `dgemv.f`, `sgemv.f`, `ddot.f`,
`daxpy.f`, `dscal.f`, `dnrm2.f90`, `dasum.f`, `idamax.f`, `dtrsm.f`, `dtrmm.f`,
`dsyrk.f`, `dsyr2k.f`, `dsymm.f` and their single
precision twins), in the reference's loop order and without fused multiply-add,
so the results are the same on every architecture. They are the equality oracle
of the tests and a public option for callers who need the reference's exact
rounding. They are not fast.

## Flags

Transpose flags are case-insensitive, as in netlib (`blas.Transpose(n)` is
`NoTrans`).

## Testing

* Per-architecture kernel tests (one worker, bit equality, packing, fences that
  fault on a one-element overrun), run natively on amd64 and arm64 and under
  qemu on riscv64, loong64, ppc64le, s390x and 32-bit arm.
* API tests over every transpose combination, odd leading dimensions, zero
  dimensions, the scalar rules, every argument error, and the bound of every
  routine against the oracle.
* A fuzz target per routine (`go test -fuzz`): no panic, and either an error or
  a result within the bound, with a committed corpus in `testdata/fuzz`.
* 100% block coverage, and `internal/cmd/guardmut`, which disables each
  argument guard in turn and requires the tests to fail by an assertion.

## Regenerating the assembly

The kernels' assembly is generated by [go-asmgen](https://github.com/go-asmgen/asmgen)
(`internal/kernels/asmgen/<arch>/gen.go`, a module of its own):

```sh
go generate ./internal/kernels         # every architecture, whatever the host
cd internal/kernels/asmgen && go run ./regen   # the same, without a shell
```
