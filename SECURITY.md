# Security

## Reporting

Report a vulnerability privately through GitHub's **Report a vulnerability**
button on this repository (Security, Advisories). Please do not open a public
issue for it.

## What the library guarantees

go-blas is pure Go (`CGO_ENABLED=0`) except for its SIMD GEMM kernels, which are
Plan 9 assembly generated by [go-asmgen](https://github.com/go-asmgen/asmgen)
for amd64, arm64, ppc64le, loong64, riscv64 and s390x. Those kernels are the only
code Go's bounds checks do not cover, and the API is meant to be bound to
Fortran-style callers (a libblastrampoline shim, for one), so it is held to the
following.

- **No routine panics on its arguments.** Every routine returns an error,
  nil or a `*ArgError` numbered as the reference's xerbla numbers it. The
  fuzz targets (one per routine, with a committed corpus) assert it, and
  every `// guard` line of the library is disabled in turn by
  `internal/cmd/guardmut`, which requires the tests to fail by an assertion.
- **Every slice is checked against what the call reads or writes**, before
  any kernel runs: `lda*(cols-1)+rows` for a matrix, `1+(n-1)*|inc|` for a
  vector. The arithmetic is overflow-safe (a length that does not fit an `int`
  is longer than any slice and is reported as too short), also on 32-bit targets,
  which CI runs (`386`, `arm`). An operand a call does not read (A and B for
  alpha = 0, C for beta = 0) is not required to exist.
- **The kernels stay inside their slices.** Each GEMM micro-kernel wrapper
  indexes the last element its kernel reads or writes before the assembly call,
  and `TestGemmMicroStaysInsideItsOperands` (Linux and macOS) maps each operand
  flush against a `PROT_NONE` page, once ending at it and once starting after
  one: a read or write one element past either end is a fault.
- **Resource use is bounded by the arguments.** The one allocation a call makes
  is a pooled scratch matrix of at most `m*n` elements, and only when `alpha`
  is neither 0 nor 1; the packed panels are fixed-size per worker.
- **Untrusted input.** Dimensions, leading dimensions and increments are
  validated before use; nothing is parsed. The only file the library reads is
  `/proc/self/auxv`, to detect SIMD extensions on loong64, riscv64 and s390x.
- **Vulnerabilities in dependencies** (`go-simd/floats`, the standard library)
  are checked by `govulncheck` in CI.

## Out of scope

Aliasing: C overlapping A, B, or x overlapping y is not detected, as in every
BLAS. Concurrent use of one output matrix by two calls is a data race.
